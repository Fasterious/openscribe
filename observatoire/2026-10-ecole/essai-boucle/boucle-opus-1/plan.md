# Plan d'analyse — scolarisation des enfants (Grand Débat 2019), 378 participants

## Étapes et ordre
1. Découpage (compétence `decouper`) par lots d'environ 40 personnes : P1-P40, P41-P80, … P361-P378.
   Après chaque lot : lire le retour de l'outil (citations introuvables, passages oubliés) et corriger avant le lot suivant.
2. Rangement (compétence `regrouper`) : livre de codes construit à partir de tout le corpus découpé, puis rangement de
   toutes les idées, relecture des frontières entre motifs voisins, balayage des non-rangés.
3. Rédaction (compétence `rediger` + `style.md`) : synthèses des motifs, grands thèmes, résumé ; traiter chaque contrôle.
4. Finaliser, puis `bilan.md`.

## Ce que je vois dans le corpus (points de vigilance)
- Beaucoup de réponses hors sujet ou de non-réponses : « pas d'enfants », « trop longtemps », « non concerné »,
  « ne comprends pas la question », contributions sans rapport (P9 décentralisation, P57 boucheries hallal, P87 ACRE,
  P295 hôpital). Il faut décider proprement : idées « non concerné » / hors sujet ; ne pas les mêler aux satisfactions.
- « Aucun problème » est une satisfaction (positif) générale ; à distinguer des satisfactions précises (enseignants,
  proximité, mairie, inscription simple, périscolaire).
- Ton jugé par rapport à l'objet : « trop d'élèves par classe » = négatif sur effectifs ; « classes non surchargées » =
  positif sur le même objet → même motif, deux camps. Même chose pour la carte scolaire : certains la défendent
  (P31, P291 mixité), d'autres veulent la supprimer (P83, P271) : minorité à garder visible.
- Grands sujets attendus : effectifs/moyens ; absentéisme et non-remplacement des professeurs ; qualité / compétence des
  enseignants (positif ET négatif) ; carte scolaire / dérogations / choix de l'établissement ; handicap et inclusion
  (AVS, MDPH, structures) ; enfants « différents » (DYS, HPI, difficulté) ; paperasse et dossiers redemandés chaque
  année, inscriptions multiples mairie/école/périscolaire ; périscolaire, garderie, horaires, rythmes scolaires,
  crèches ; orientation, Parcoursup/APB, réforme du bac ; enseignement supérieur (coût, bourses, CROUS, logement) ;
  baisse du niveau, nivellement par le bas, méthodes pédagogiques ; harcèlement, discipline, sécurité ; fuite vers le
  privé (et satisfaction dans le privé) ; écoles rurales (fermetures de classes, classes multiniveaux, transports
  scolaires ; mais aussi satisfaction de la petite école de village) ; égalité des chances / inégalités territoriales
  et sociales ; communication avec les enseignants / la direction ; langues vivantes ; déménagement / changement
  d'académie.
- Administrations citées : Éducation nationale, mairie/commune, rectorat/académie, CAF, CROUS, MDPH, département,
  région. Les garder dans les idées quand elles sont dites.
- Ne pas inventer de chiffres. Compter les personnes : une personne qui dit trois fois « classes surchargées » compte une fois.
- Réponses longues (P57, P91-92, P233, P252, P272, P361) : découper finement, un objet par idée, citation exacte.
- Fautes d'orthographe dans les réponses : citer tel quel, mot pour mot.

- Rédaction : 51 synthèses, 9 thèmes, résumé ; finalisé, puis bilan.md.
